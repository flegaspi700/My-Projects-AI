# My-Projects-AI

A compilation of code and experiments for learning about AI agents, the Google Gemini API, and Google's Agent Development Kit (ADK).

This repository includes examples covering:

- Gemini API calls and conversations
- Streaming and multimodal responses
- Tool use and function calling
- AI agent workflows
- Google ADK examples

The projects are intended for learning, experimentation, and exploring how modern AI applications are built with Python.
